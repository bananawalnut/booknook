## Packaging and release boundary

New reference-app code is MPL-2.0; new core/SDK code is MIT OR Apache-2.0, with explicit upstream notices and dependency inventory. Optional adapters have their own declared dependencies and license boundaries. Source, native development apps and SDK archives are local deliverables. Static ontology hosting and optional personal services have reproduction instructions. Development signing was used for the separate physical iPad QA app. No remote CI success, public package/ontology publication, distribution signing/notarization, store submission or real-account authorization is implied.

The browser app, automatic narration following, unrestricted Kindle content, live collaborative notebooks and direct peer connections remain outside the approved first-release promises. Keeping those out does not reduce the requested native MVP or excuse its remaining integration and hardware gates.
